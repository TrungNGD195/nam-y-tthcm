# Tài liệu gốc theo môn

- `tthcm/`: tài liệu Tư tưởng Hồ Chí Minh đã chuyển từ `Theory_and_questionbank/`.
- `xu-ly-anh/`: đặt giáo trình, slide, ngân hàng Xử lý ảnh khi có.
- `khoa-hoc-du-lieu/`: đặt giáo trình, slide, ngân hàng Khoa học dữ liệu khi có.

File gốc không đẩy lên GitHub hoặc tải cùng website. Đặt tài liệu vào đây chưa tự xuất bản câu hỏi; cần đọc, chia chương và kiểm chứng nội dung trước.
